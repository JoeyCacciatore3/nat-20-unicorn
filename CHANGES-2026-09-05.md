## 1. Boss AI — Uniform Kit, Tier-Scaled Difficulty (−68 B)

**What changed:**
- All 7 DARKCORN bosses now use the **identical 3-move kit**: jump + dash + shoot. Previously only RED/ORANGE/YELLOW used shoot; bosses were inconsistent in ability.
- Removed the **per-boss phase-2 escalation table** (`P2` array): no more summon/swift/shockwave grants at half HP.
- Single universal phase-2 enrage: **1.5× speed multiplier** on chase and hop movements.
- **Difficulty comes purely from tier (bi):**
  - HP: `(16 + bi×4) × (2 + lvl>>2)` — base + tier bonus + level scaling
  - Damage: `8 + bi` (unchanged)
  - Speed: `1 + bi×0.1` (chase/hop speed ramp; phase 2 multiplies by 1.5)

**Why:**
- Consistent player experience — every boss feels like a "full unicorn" encounter.
- Tier-scaling creates natural progression without adding code complexity.
- Tier-indexed RED (8 HP, 1.0× speed) → INDIGO (2.2× HP, 1.6× speed, full phase 2 boost).

**Bytes:** Removed P2 table import + three entire dead-code branches (summon/swift/shockwave) → **+68 B free**.

## 2. Skill Tree Rebuild — 14→10 Nodes, Fixed Baselines (−44 B)

**Removed skills (modifier-only, no upgrade paths):**
1. STASH (+5 bag slots) — inventory now fixed at 10 from the start
2. HP +5 (skill-based stat) — base formula cleaned to `8 + HP-stat×2` only
3. MP +5 (skill-based stat) — base formula cleaned to `8 + MAG-stat×2` only
4. POT +5 (skill-based potion heal) — potion heal flat 10 HP / 10 MP

**Remaining 10 nodes (all action skills):**
- Row 1: SHOT, HEAL, DASH (always available)
- Row 2: DBL JUMP, LONG DASH (prereq-gated via DASH)
- Row 3: TRI JUMP (prereq-gated via DBL JUMP)
- Row 4: SUPER HEAL, FAR SHOT, DBL SHOT, TRI SHOT (endgame capstones)

**The rewire (critical for consistency):**
- Old indices 0–7 → unchanged
- Old indices 12–13 (DBL/TRI SHOT) → new indices 8–9
- **Prerequisite link graph (LINK) fully rewired** to keep all 10 nodes reachable:
  - Roots: SHOT, HEAL, DASH (no parents)
  - SUPER HEAL & FAR SHOT now reach via TRI JUMP (their old MP+5/POT+5 parents are gone)
  - DBL/TRI SHOT chain: SHOT → DBL SHOT → TRI SHOT
- **Save format bumped v43→44** — old saves with wrong `su[]` indices are cleanly discarded on load

**Why:**
- Simpler progression: no invisible stat inflation from skills.
- Inventory UI cleaner: 10 slots is the max the grid displays well.
- Potion system transparent: flat heal makes potion-stacking strategy readable.
- Action skills only: every purchase unlocks a new *play experience*, not just a number bump.

**Bytes:** Removed 4 literals + stat formula terms + P2 precedent + comment cleanup → **+44 B free**.
